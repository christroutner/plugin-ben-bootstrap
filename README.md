# @chris.troutner/plugin-ben-bootstrap

This is a plugin for an [Eliza](https://github.com/elizaOS/eliza) AI agent. It's forked from the `plugin-bootstrap` plugin from v1.0.0-beta.32.

This boostrap plugin is being customized for the Ben AI agent project. It's optimized to work with the llama3.1:8b-instruct-q4_K_M LLM model, and for the use-case of a library or knowledge-base chat bot.
